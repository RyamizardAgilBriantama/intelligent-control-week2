Analisis

1.Bagaimana performa model dalam mendeteksi warna?
Performa model dalam mendeteksi warna sangat dipengaruhi oleh kualitas dan keragaman data dalam dataset (color.csv). Algoritma K-Nearest Neighbors (KNN) pada kode memanfaatkan nilai RGB untuk mengklasifikasikan warna. Jika dataset memiliki distribusi warna yang seimbang dan bervariasi, maka akurasi deteksi warna akan tinggi. Sebaliknya, dataset yang tidak merata akan menurunkan kinerja model. Evaluasi performa yang lebih objektif dapat dilakukan menggunakan metrik seperti akurasi, precision, recall, dan F1-score dengan membandingkan prediksi model terhadap label sebenarnya.

2.Bagaimana perbedaan akurasi jika jumlah dataset ditambah?
Penambahan jumlah data umumnya dapat meningkatkan akurasi model, terutama jika data tambahan memperkaya variasi warna dan mencakup lebih banyak contoh. Hal ini membantu model mengenali pola warna yang lebih kompleks. Namun, jika data yang ditambahkan mengandung banyak noise, akurasi dan kinerja model justru dapat menurun.

3.Bagaimana cara meningkatkan kinerja model klasifikasi?
Beberapa cara untuk meningkatkan kinerja model klasifikasi antara lain:

Hyperparameter tuning: Mencoba berbagai nilai k pada KNN untuk menemukan parameter yang optimal.

Eksperimen algoritma lain: Mempertimbangkan algoritma seperti Random Forest atau Support Vector Machine (SVM) untuk hasil klasifikasi yang mungkin lebih baik.

Feature engineering: Menambahkan fitur tambahan seperti nilai HSV atau LAB yang lebih representatif daripada RGB saja.

Cross-validation: Menggunakan validasi silang untuk mengevaluasi performa model secara lebih akurat dan menghindari overfitting.

Diskusi

1.Apa keuntungan Machine Learning dibandingkan metode berbasis aturan (rule-based)?
Machine Learning memiliki fleksibilitas yang jauh lebih tinggi dibandingkan metode berbasis aturan karena tidak memerlukan penulisan aturan secara manual. Model ML mampu belajar langsung dari data, menemukan pola yang sulit dipahami manusia, dan dapat beradaptasi dengan data baru. Seiring bertambahnya data, akurasi model juga cenderung meningkat, berbeda dengan sistem rule-based yang sulit beradaptasi tanpa pembaruan manual.

2.Bagaimana ML dapat diintegrasikan lebih lanjut dalam sistem kendali?
Machine Learning dapat diimplementasikan lebih dalam pada sistem kendali untuk meningkatkan efisiensi dan kemampuan adaptasi. Contohnya, dalam sistem otomasi, ML dapat digunakan untuk mendeteksi objek secara real-time melalui kamera dan mengirimkan perintah ke aktuator untuk mengambil keputusan secara otomatis. Selain itu, ML juga dapat dimanfaatkan untuk memprediksi kondisi sistem dan melakukan optimasi, seperti mengatur parameter kendali sesuai perubahan lingkungan.

3.Apa saja tantangan dalam penerapan ML dalam sistem real-time?
Tantangan utama penerapan ML pada sistem real-time mencakup:

Keterlambatan dalam proses pengambilan keputusan.

Keterbatasan sumber daya perangkat keras seperti CPU, GPU, dan memori, khususnya pada perangkat embedded.

Ketergantungan pada data sensor yang dapat terganggu oleh kondisi lingkungan yang dinamis dan penuh noise.

Risiko overfitting jika model tidak diperbarui secara berkala dan tidak dilatih dengan dataset yang beragam.
